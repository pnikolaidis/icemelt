# Scratch Itch Software Homebrew Tap

Homebrew tap for [Scratch Itch Software](https://scratchitchsoftware.com) apps.

## Usage

```sh
brew install --cask pnikolaidis/tap/icemelt
```

## Available casks

| Cask | App | Description |
| --- | --- | --- |
| `icemelt` | [IceMelt](https://github.com/pnikolaidis/icemelt) | Menu bar manager for macOS 26+ (Tahoe), fork of [Ice](https://github.com/jordanbaird/Ice) |

IceMelt updates itself via Sparkle after installation, so `brew upgrade` is not required to stay current (`auto_updates true`).
